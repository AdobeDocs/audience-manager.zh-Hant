# 密碼要求、鎖定的帳戶及忘記密碼{#password-requirements-locked-accounts-and-forgotten-passwords}

Audience Manager 可將密碼設定為每隔 30 天過期。 如需啟用密碼過期功能，請洽詢您的 Audience Manager 顧問或客戶服務。 請參閱本節內容，瞭解密碼要求以及如何復原遺失或忘記的密碼。

**密碼要求**

您的 [!DNL Audience Manager] 密碼必須符合下列要求才會有效：

| 要求 | 說明 |
|---|---|
| 長度 | 密碼長度可介於 12 到 40 個字元。 |
| 內容 | 密碼必須：<ul><li>以英數字元開始和結束。</li><li>至少包含一個大寫字元和一個小寫字元。</li><li>至少包含一個數字。</li><li>至少包含一個特殊字元（不含冒號）。</li><li>僅包含拉丁字母。</li></ul> |
| 版本 | 密碼必須與前 12 個密碼不同。 |
| 禁止專案 | 密碼不得包含：<ul><li>您的名字或姓氏。</li><li>您的電子郵件地址或[!DNL Adobe]使用者識別碼。</li><li>連續的字母或數字。</li><li>循序字母或數字。</li><li>常用密碼。</li></ul> |

如需重設密碼的詳細資訊，請參閱[編輯帳戶設定](../features/administration/edit-account-settings.md)。

**帳戶鎖定**

為了安全起見，[!DNL Audience Manager]暫時限制重複失敗的登入嘗試。 如果超過限制，[!DNL Audience Manager]會在短時間內封鎖進一步的登入嘗試，然後自動允許再次登入。 您不需要連絡管理員或合作夥伴服務代表，即可解除鎖定帳戶。

**遺失/忘記密碼**

在登入頁面上選取&#x200B;**[!UICONTROL Forgot password]**&#x200B;以重設您的密碼。 [!DNL Audience Manager]傳送一封電子郵件給您，其中包含重設密碼的連結。 選取連結，然後建立符合密碼要求的新密碼。 此連結只會運作一次。

**新帳戶設定**

管理員建立您的帳戶時，[!DNL Audience Manager]會傳送一封電子郵件給您，其中包含設定密碼的連結。 選取連結，然後建立符合密碼要求的密碼。 第一次登入前，您必須先設定密碼。
